note-draft 書式対応パッチ v3 ── 導入手順

================================================
v3 で足したもの
================================================
・入稿前に中身を確認する「プレビュー」を追加（src/preview.ts）
・画像の差し込み位置を、実行中にターミナルへ出すようにした
・直前が「引用」の行だと画像が引用の内側に入っていたのを修正
・画像の目印を長めに取り、複数に当たったときは警告を出すようにした

================================================
入れ方（ターミナルに丸ごと貼ってEnter）
================================================

cd ~/Downloads
Z=$(ls -t note-draft-patch*.zip | head -1)
echo "使うファイル: $Z"
rm -rf _patch_tmp && mkdir _patch_tmp
unzip -oq "$Z" -d _patch_tmp
cp _patch_tmp/note-draft-patch/src/*.ts ~/note-kit/note-draft/src/
cd ~/note-kit/note-draft
grep -c "openBlankLineForImage" src/noteEditorAdapter.ts
npm run typecheck

※ grep の数字が 2以上、typecheck で赤い文字が出なければ成功です。

================================================
入稿前に、中身をターミナルで見る
================================================

cd ~/note-kit/note-draft
npx tsx src/preview.ts articles/senryaku-senni-ritsu

見出し・小見出し・引用・太字・画像の位置が、ぜんぶ一覧で出ます。
長いときは less を付けてください：

npx tsx src/preview.ts articles/senryaku-senni-ritsu | less

================================================
入稿する
================================================

cd ~/note-kit/note-draft && npm run draft -- articles/senryaku-senni-ritsu --headed

実行中、画像ごとにこう出ます：

  step: "image-place"
  file: "fig1.png"
  anchor: "伸びた＝効いた、ではありません。"
  placed: true     ← false なら目印が見つからず末尾に入っています
