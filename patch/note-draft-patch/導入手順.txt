note-draft 書式対応パッチ v2 ── 導入手順

================================================
v1 からの変更
================================================
・型チェックのエラーを修正（npm run typecheck が通るようにした）
・ボタンを aria-label / title まで見て探すようにした（小見出し対策）
・小見出しのボタンが無い場合は、その行を太字にして代用する
・当てられなかったときの画面ボタン一覧を、より詳しく出すようにした

v1 の結果：大見出し7/7、引用12/12、太字41か所 → すべて自動
　　　　　 小見出し 0/14 がボタン名不明で残っていた

================================================
入れ方（ターミナルに丸ごと貼ってEnter）
================================================

cd ~/Downloads
unzip -oq note-draft-patch.zip
cp note-draft-patch/src/*.ts ~/note-kit/note-draft/src/
cd ~/note-kit/note-draft
npm run typecheck
echo "--- エラーが出なければ成功 ---"

※ バックアップは v1 のときに ~/note-kit/note-draft/_backup_src/ に作ってあります。
　 元に戻すときは：
　 cp ~/note-kit/note-draft/_backup_src/*.ts ~/note-kit/note-draft/src/

================================================
試す
================================================

cd ~/note-kit/note-draft && npm run draft -- articles/senryaku-senni-ritsu --headed

※ 下書きは毎回「新しい記事」として作られます。
　 前回の下書きが残るので、不要なら note の画面で削除してください。

================================================
見るところ
================================================
ターミナルの body-format の行を見てください。

  h3: 14   → 小見出しも自動で入った（完成）
  h3: 0, boldFallback: 14 → 小見出しは太字で代用された

後者だった場合は、そのすぐ下の visibleButtons の一覧を送ってください。
