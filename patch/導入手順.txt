note-draft 書式対応パッチ ── 導入手順

================================================
何が変わるか
================================================
今まで：article.md の ## ** > ``` は、noteに入る前に消されていた
      → noteには素のテキストだけが入り、手で太字・見出し・引用を設定していた

これから：
  ##  →  大見出し
  ### →  小見出し
  **  →  太字
  >   →  引用
  ``` →  引用（記号は出ない）
  |表| →  読みやすい1行に変換
  - 箇条書き → ・（今までと同じ）

================================================
入れ方（ターミナルに丸ごと貼ってEnter）
================================================

cd ~/note-kit/note-draft/src
mkdir -p ../_backup_src
cp types.ts articleParser.ts noteEditorAdapter.ts ../_backup_src/
cd ~/Downloads
unzip -oq note-draft-patch.zip
cp note-draft-patch/src/*.ts ~/note-kit/note-draft/src/
cd ~/note-kit/note-draft
npm run typecheck || npx tsc --noEmit
echo "--- エラーが出ていなければ成功です ---"

================================================
元に戻したくなったら
================================================

cp ~/note-kit/note-draft/_backup_src/*.ts ~/note-kit/note-draft/src/

================================================
動かし方（今までと同じ）
================================================

cd ~/note-kit/note-draft && npm run draft -- articles/senryaku-senni-ritsu --headed

================================================
うまくいかなかったとき
================================================
ターミナルに出た表示を、そのまま送ってください。
特に「見出し・引用を当てられなかった行があります」と出た場合、
そのすぐ後ろに visibleButtons という一覧が出ます。
その一覧があれば、ボタン名を直して1回で直せます。

※ 書式が当たらなかった行は、今までと同じ素のテキストで残ります。
　 下書きが作られなくなったり、画像が入らなくなったりはしません。
