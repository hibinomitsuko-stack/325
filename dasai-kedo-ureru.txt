タイトル：「綺麗だけど、売れないんだよね」と言われました。足りなかったのは、センスではありませんでした
タグ：デザイン / Webデザイン / マーケティング / デザイナー / フリーランス

==============================================


「このデザイン、綺麗なんだけど……売れないんだよね」

納品のあとに言われました。

褒められたのか、だめだと言われたのか、分かりませんでした。

何を直せばいいのか分からなくて、私はこう答えました。

「もっと綺麗にします」

それが見当違いだったと気づくまで、かなりかかりました。当時の私にとって、デザインの良し悪しは、見た目の良し悪しとほとんど同じ意味だったからです。

そのクライアントからの依頼は、そのあと半年ほど止まりました。

何年かあとに、別のクライアントから逆のことを言われました。

「あなたのデザイン、ダサいけど売れるね」

正直、最初は複雑でした。でも今は、いちばんうれしい言葉です。

センスが上がったわけではありません。変えたのは、考える順番だけでした。

  ◇ 先に、この記事の範囲を書いておきます

この記事で書くのは、LP、バナー、チラシ、告知画像など、売るためのデザインの話です。

そして、売上はデザインだけで決まりません。商品、価格、コピー、集客、タイミング。どれも効きます。

デザインができるのは、見た人が気づく・分かる・信じる・動くときの迷いを減らすところまでです。

私は、その役割を長いあいだ分かっていませんでした。

■ 時間をかけていたのは、成果に関係のない場所でした

当時、1本のLPに何日もかけていました。やっていたのは、こういうことです。

```
余白のバランスを何度も調整する
フォントを7種類ためして1つに決める
色の階調を少しずつ変えて見比べる
写真の明るさを微調整する
```

全部、見た目を整える作業です。

丁寧ではありました。でも、クライアントが求めていたのは、丁寧に作られた画面そのものではありませんでした。

その画面を見たお客さんが、商品を分かって、安心して、問い合わせまで進むことでした。

  ◇ フォントを7種類ためしても、買う理由は増えません

作っているあいだ、私はその商品を何度も見ています。説明文も読み、写真も見比べ、背景も聞いています。

できあがるころには、私がいちばん詳しい人になっています。

だから、初めて見た人がどこで迷うのかに気づけません。

自分には分かる。でも、初めて見た人には分からない。その差を、私はフォントと余白で埋めようとしていました。

何の商品か伝わらなければ、フォントを7種類ためしても売れません。買う理由が見えなければ、余白を1ピクセル直しても動けません。

「綺麗だけど売れない」は、作り手だけが全部分かっている状態のことだったんだと思います。

［図1］時間をかけていた場所と、相手が迷っていた場所

■ 美しさを捨てたのではなく、使う順番を変えました

作業の中身は、以前とそれほど変わりません。変えたのは、取りかかる順番です。

```
以前　整える　→　目立たせる　→　分かりやすくする

今　　目的を決める　→　止まる　→　分かる　→　信じる　→　動ける　→　最後に整える
```

以前は、何を伝えるかが決まらないまま、綺麗にし始めていました。

今は先に、誰に、何を伝えて、次にどう動いてほしいかを決めます。そのあとで、順番に確認します。

```
・自分に関係があると気づけるか　（止まる）
・何の商品か分かるか　　　　　　（分かる）
・本当だと思えるか　　　　　　　（信じる）
・次に何をすればいいか分かるか　（動ける）
```

整えるのは、いちばん最後です。

美しさがいらない、という話ではありません。 読みやすさも、信頼感も、ブランドらしさも、整えることで出ます。

先に飾るのをやめて、伝わる骨組みを作ってから整えるようになった、というだけです。

［図2］以前の順番と、今の順番

  ◇ 作業時間は、むしろ減りました

以前は、正解が分からないまま色とフォントをためしていました。目的が決まっていないので、どれを選んでも不安が残ります。

今は、判断の基準が先にあります。

```
この人に伝わるか
この情報が最初に見えるか
次の行動のじゃまをしていないか
```

基準に合わない案は、早い段階で外せます。迷う時間が減ったぶん、最後の調整に時間を回せるようになりました。

■ 今日、無料でできる「3秒テスト」

最近つくったLPの最初の画面、バナー、チラシ。どれでもいいので1つ開いてください。

3秒だけ見て、閉じます。

そのあと、この3つを書きます。

```
何の商品・サービスだったか
誰のためのものだったか
次に何をすればよかったか
```

3つとも出てこなければ、綺麗さを調整する前に直す場所があります。

  ◇ 自分でやると、答えられてしまいます

自分の制作物は、中身を知っているので簡単に答えられます。

できれば、その商品を知らない人に同じテストをしてください。

そのとき、「どう思った？」とは聞かないでください。

```
「何の商品だった？」
「誰向けだと思った？」
「次に何を押せばよかった？」
```

見えた内容だけを聞きます。感想を聞くと、相手は気をつかって「綺麗」「おしゃれ」と答えてくれるからです。

  ▶ 今日は、答えられなかった項目を1つ見つけるだけで大丈夫です。作り直さなくていいです。

■ 作り始める前に、1行だけ決めます

4つに入る前に、これを書きます。

```
〔誰〕に、〔何〕を伝えて、〔どう動いて〕ほしいか
```

たとえば、近所の整体院のチラシなら、こうなります。

```
肩こりを何年も我慢してきた40代の方に、
初回で何をするのかが先に分かることを伝えて、
電話で予約してほしい。
```

この1行が、そのあとの判断基準になります。色やフォントで迷ったときに、「どちらが好きか」ではなく「どちらがこの1行を早く伝えられるか」で決められるようになります。

書けないときは、作り始める前にクライアントに聞いてください。ここが決まっていない状態で進めると、あとで戻ります。

ここまでが、順番を間違えていた、という話と、その手前で決めることです。

ただ、「止まる」「分かる」「信じる」「動ける」と言われても、それぞれ何を見ればいいのかは分かりにくいと思います。

この先に書くのは、4つそれぞれの確かめ方と、15分で直す場所を1つに絞る手順、そして「もっと綺麗に」と言われたときの返し方です。

■ ①止まる｜派手にするのではなく、「自分に関係がある」と気づかせます

見てもらえなければ、その先はありません。

ただし、止めることと、派手にすることは違います。

人が止まるのは、「これは自分に関係がある」と気づいたときです。

  ◇ 競合と変えるのは、1軸だけ

同じ商品・サービスの競合を、3つ開いてください。

見るのは色だけではありません。「最初に何を約束しているか」「どんな写真か」「いちばん大きい文字は何か」。共通しているものをメモします。

そのうえで、言葉・写真・文字の大きさ・色のうち、1軸だけ変えます。

```
競合が全員「高品質」と言っている　→　自分だけ、具体的な場面を出す
競合が商品の写真ばかり　　　　　　→　使ったあとの様子を見せる
競合の文字が全部同じ大きさ　　　　→　1行だけ極端に大きくする
```

色は、必ずしも変えなくていいです。

淡い色が多い業界だからといって反対色にすると、ブランドの印象や、文字の読みやすさを壊すことがあります。そこまでして違わせると、今度は信用のほうを失います。

目的は「違う色にすること」ではなく、「自分に必要な情報だと気づいてもらうこと」です。

［図3］競合と変えるのは、1軸だけ

■ ②分かる｜3秒で答えられない情報は、ないのと同じです

止まったあと、見た人は短い時間で判断します。

3秒という数字に根拠があるわけではありません。ただ、「読めば分かる」ではなく「最初の画面でつかめる」状態を作るために、私はこれを目安にしています。

  ◇ 頼める人がいないときの、代わりの方法

一晩おいて翌朝に見るか、スマホで撮って数日後に開きます。他人の目と同じにはなりませんが、作業中よりは距離が取れます。

もうひとつ、画面を小さく表示する方法があります。縮小したときに残っている情報が、今いちばん強い情報です。そこが伝えたいことと違っていたら、②がまだ済んでいません。

■ ③信じる｜綺麗さより先に、不安を1つ消します

何の商品か分かっても、「本当かな」と思われたままでは動けません。

ここで要るのが、信じるための材料です。

```
具体的な数字　／　利用した人の声　／　前と後の比較
実際に使っている場面　／　保証やサポート
```

全部は入れないでください。

その商品でいちばん大きい不安を1つ選んで、それを消す材料を1〜2個だけ置きます。

さっきの整体院なら、こうなります。

```
痛くないか不安　　　　　→　初回の流れ、かかる時間
通い続けるのか不安　　　→　回数の目安、無理にすすめない旨
自分の症状で合うか不安　→　似た症状の人の声
```

受賞歴をきれいに並べるより、買う直前に迷っていることに答える材料を選びます。

■ ④動ける｜次の行動を、1つだけ残します

止まって、分かって、信じても、次に何をすればいいか分からなければ動けません。

確かめるのは3つです。

```
行動が1つに絞られているか
ボタンの言葉が具体的か
押したあとに何が起きるか分かるか
```

```
×  詳しくはこちら　　→　○  初回の流れを見る
×  お問い合わせ　　　→　○  チラシの相談をする
```

押したあとが想像できる言葉にして、ボタンのすぐ近くに、最後の不安を消す一言を置きます。

```
入力は1分で終わります
相談だけでも大丈夫です
2営業日以内にお返事します
```

ボタンを目立たせるのではなく、押せない理由を減らすほうが効きました。

■ 最後に整える｜美しさは、成果の敵ではありません

4つが済んだら、最後に整えます。

```
文字は読みやすいか
余白にばらつきがないか
写真のトーンがそろっているか
ブランドらしい印象になっているか
スマホで、大事な情報が見えているか
```

ここで初めて、フォント、色、余白、写真の明るさを細かく調整します。

美しさは、いらないものではありません。 読みやすくして、信頼を支えるために要ります。ただ、伝える内容が決まる前に美しくしても、判断する基準がありません。

「ダサい」を目指すのでも、「綺麗」を捨てるのでもありません。綺麗さに、仕事をさせる順番に変えるということです。

  ◇ 途中から始めると、こうなります

```
整えることから入る　→　綺麗だが、何を伝えたいのか弱い
証拠を詰め込む　　　→　強そうだが、広告っぽくて読まれない
ボタンだけ大きく　　→　押す理由がないまま、売り込まれて見える
```

1つずつの技術より、順番でした。

■ 実際にやってみる（15分）

［図4］15分でできる、販促デザイン診断

  ◇ 3分｜目的を1行にする

```
〔誰〕に、〔何〕を伝えて、〔どう動いて〕ほしいか
```

書けなければ、まずここが直す場所です。

  ◇ 3分｜3秒テストをする

最初の画面だけを3秒見て、「何の商品か」「誰向けか」「次に何をするか」を書きます。

  ◇ 4分｜信じる材料を1つ探す

いちばん不安に思われそうなことを1つ書いて、それを消す材料を探します。見つからなければ、クライアントに聞く項目になります。

  ◇ 3分｜次の行動を確かめる

ボタンや連絡先を見て、押したあとが想像できるかを見ます。

  ◇ 2分｜直す1か所を決める

```
止まらない　　　→　最初の言葉か、写真
分からない　　　→　いちばん大きい1行
信じられない　　→　不安を消す材料
動けない　　　　→　ボタンの言葉か、その近くの一言
```

全部直さないでください。 いちばん手前で止まっている1か所だけを直します。

■ 「もっと綺麗に」と言われたときの返し方

要望を無視する話ではありません。ただ、言われたまま装飾を足す前に、意図を1行で説明します。

```
ここは〔誰〕に〔何〕を最初に伝える場所なので、
〔文字を大きく／余白を狭く／ボタンを強く〕しています。
見た目を整えつつ、この優先順位は残す形で調整します。
```

実際に使うと、こうなります。

```
ここはスマホで最初に見える部分なので、
初めての方にも料金がすぐ分かるよう、数字を大きくしています。
色味を整えつつ、料金の見つけやすさは残す形で調整します。
```

理由が分かると、話が好みだけで進みにくくなります。

デザイナーのこだわりではなく、見る人の行動を基準に相談できるようになりました。

  ◇ つまずいたときの、3つの分かれ道

① 競合と違わせると、ブランドらしくなくなる

色を変える必要はありません。言葉、写真、見せる順番、大きさのどれか1つで差を作ってください。ブランドを壊さない軸を選べば足ります。

② 3秒テストを頼める人がいない

一晩おく、数日後に見る、縮小して見る。この3つで代用できます。

③ 4段階を整えても、売れない

デザインの外を見てください。

```
商品自体に需要があるか
価格と価値が合っているか
必要な人がそのページに来ているか
コピーが具体的か
申し込みの条件に不安がないか
```

デザインでできるのは、伝わり方と行動の摩擦を減らすところまでです。商品や集客の問題まで、デザインの失敗にしないでください。 私はしばらく、全部自分のせいにしていました。

  ▶ 今日は、4つのどこで止まっているかが分かれば十分です。

■ おわりに

「綺麗だけど、売れないんだよね」と言われたとき、私は綺麗さが足りないのだと思いました。

だから、もっと綺麗にしようとしました。そして半年、依頼が止まりました。

足りなかったのは、綺麗さではありませんでした。考える順番でした。

今は「ダサいけど売れるね」と言われます。褒め言葉として受け取っています。

ただ、目指しているのはダサいデザインではありません。見た人が止まって、分かって、信じて、迷わず動けるデザインです。

その骨組みを作ってから、最後に綺麗に整える。

センスは急に変えられませんが、順番なら今日から変えられます。
