タイトル：「ポートフォリオ？見てないですよ」決め手は、作品を1枚も添えなかった最初の1行でした
タグ：フリーランス / デザイナー / 案件獲得 / ポートフォリオ / 個人起業

==============================================


「ポートフォリオ？見てないですよ」

納品の直前に、そう言われました。

120万円かけて、スクールで作った作品集です。卒業してからも直し続けて、Webサイトにもまとめて、応募のたびにリンクを貼っていました。

その作品集は、一度も開かれていませんでした。

思い切って聞いてみました。「じゃあ、何を見て私に決めたんですか？」

返ってきたのは、「最初のメッセージです」でした。

■ 決め手になったのは、ヤケクソで送った1行でした

送ったのは、これだけです。

  ▶ 「御社の商品、スマホだと一番伝えたい魅力が途中で消えてしまっているのが、少しもったいないと感じました」

偉そうかな、と思いました。でも他に思いつくこともなくて、半分ヤケで送った一言です。

作品は、1枚も添えていません。

それから8年たちましたが、120万円のポートフォリオを実際に見せた回数は、ゼロです。

  ◇ その前に、122件落ちています

8年前の私は、逆のことをしていました。

```
架空のLPを50個つくる
バナーもロゴも写真も用意する
プロフィールを書き直す
「見せられるもの」を、とにかく増やす
```

そのうえで、クラウドワークスに122件応募しました。決まったのは0件です。

いちばんこたえたのは、落ちたことではありません。

「ポートフォリオを見せてください」と、一度も言われなかったことでした。

作品を見られて落ちたのではなく、作品にたどり着く前の場所で止まっていたんです。

［図1］決め手になったのは、作品ではなく1行でした

■ ポートフォリオは、入口ではありませんでした

クライアントが最初に知りたいのは、「どんな作品が作れる人ですか？」ではありませんでした。

「この人、私の困っていること分かってる？」です。

```
×  LP制作できます。こちらがポートフォリオです。
○  御社の商品、スマホだと一番伝えたい魅力が
   途中で消えてしまっているのが、少しもったいないと感じました。
```

この一言があるだけで、初めて「詳しく聞かせてください」になりました。

作品を見てもらえるのは、そのあとだったんです。

  ◇ 順番が、逆でした

ポートフォリオは、仕事を取るための入口ではありません。

「この人に相談してみたい」と思われたあとに、安心するために見るものです。

順番にすると、こうなります。

```
1｜1行で「分かってる？」に答える
2｜「詳しく聞かせてください」と言われる
3｜そこで初めて、作品を見てもらう
```

私は、3番目だけを8年前にひたすら磨いていました。

  ◇ 量産型ポートフォリオが避けられる理由

あとから採用する側にもまわって、200人以上のポートフォリオを見ました。そこで分かったのは、私が作っていたものが、いちばん時間を奪うタイプだったということです。

```
・架空プロジェクトばかり並べる
・業界も目的も違う作品を詰め込む
・クライアントのゴールが見えない
```

見る側は、この中から「自分の案件に近いもの」を探す作業をさせられます。数が多いほど、その作業は増えます。

［図2］ポートフォリオを見てもらえる順番

  ◇ 今日、無料でできること

作品を1つ増やす前に、気になる会社を1社だけ見てください。

そして、1つだけ考えます。「この会社、何に困っていそう？」

その1行のほうが、作品を10個増やすより仕事につながることがあります。

  ▶ 今日はここまでで十分です。まだ送らなくて大丈夫です。

ここまでが、Threadsにも書いた話です。

ただ、「1社見て考える」と言われても、何を見ればその1行が出てくるのかが分からないと思います。私も、あの1行は偶然のヤケクソでした。

そのあと8年かけて、同じ形の1行を何度も送れるようにしました。この先に書くのは、あの1行を再現するための3つの材料と、送る前の確認、そして15分の手順です。

━━━━━━━━━━━━━━━━━━━━━━━━
★★★  ここから有料エリア（100円）  ★★★
   note編集画面で、この位置に有料ラインを引く
━━━━━━━━━━━━━━━━━━━━━━━━

■ あの1行は、3つの材料でできています

送った文を、分解します。

  ▶ 「御社の商品、スマホだと／一番伝えたい魅力が途中で消えてしまっている／のが、少しもったいないと感じました」

バラバラに見えますが、毎回同じ3つが入っています。

  ◇ 材料①｜どこを見たか（場所を1つに絞る）

「御社の商品、スマホだと」の部分です。

ここで、見た場所を1つに限定しています。サイト全体でも、ブランド全体でもありません。

場所を絞ると、相手が確認できるようになります。「どこの話？」と思わせた時点で、読まれません。

絞り方は、だいたいこの4つで足ります。

```
・スマホで見たときの1画面目
・申し込みボタンまでの道のり
・商品写真の1枚目
・SNSのプロフィール欄
```

どれもクリック2回以内で見られる場所です。調べる時間は5分で足ります。

  ◇ 材料②｜誰が困るか（自分ではなく、相手のお客さん）

「一番伝えたい魅力が途中で消えてしまっている」の部分です。

ここで困っているのは、クライアントではありません。クライアントのお客さんです。

ここを間違えると、こうなります。

```
×  デザインが古いと感じました       → 相手を否定している
×  私ならもっと良くできます         → 自分の話に戻っている
○  一番伝えたい魅力が途中で消えている → 相手のお客さんの話
```

主語を「相手のお客さん」に置くと、同じ指摘でも、ダメ出しではなく共有になります。

  ◇ 材料③｜言い切らない（断定しない語尾）

「のが、少しもったいないと感じました」の部分です。

「直したほうがいいです」でも「改善できます」でもありません。感じましたで止めています。

まだ中を知らない相手に言い切ると、偉そうになります。「少し」「もったいない」「感じました」の3つで、角が取れています。

実際、送るとき私も偉そうかなと思いました。でも、言い切っていなかったから成立したんだと思います。

［図3］1行をつくる3つの材料

■ 作品は、そのあと1〜2個で足ります

最初から全部そろえる必要はありません。

「詳しく聞かせてください」と言われてから、その案件に近いものを1〜2個出せば足ります。50個はいりません。

そして、出すときに作品の横へ3行だけ足します。

```
1行目｜相手は何に困っていたか
2行目｜そこで何をしたか
3行目｜そのあとどうなったか
```

よくあるのは、こう書いてしまうパターンです。

```
×  カフェのロゴ／Illustrator／制作期間2週間
```

これは、私の作業内容です。3行にすると、こうなります。

```
○  1｜店名を覚えてもらえず、紹介で来た人が店を通り過ぎていた
    2｜看板で遠くから読める形を優先して、字の太さと余白を決めた
    3｜「場所を聞かれる回数が減った」と言われた
```

この3行は、自主制作でも書けます。「架空の案件として作りました」と先に書けば、嘘にはなりません。相手が見たいのは成果の大きさではなく、この人は何を見て判断するのかだからです。

■ 実際にやってみる（15分）

［図4］1社ぶんの1行をつくる

  ◇ ステップ1｜1社だけ選ぶ（3分）

応募したい会社でも、気になるお店でも構いません。1社だけです。

選べないときは、自分がお客として使ったことがある会社にしてください。困りごとが見えやすくなります。

  ◇ ステップ2｜場所を1つ決めて、スマホで見る（5分）

材料①の4つから、1つだけ選びます。パソコンではなく、スマホで開いてください。

そこで、自分が「あれ」と思った瞬間をメモします。うまく言えなくて大丈夫です。

  ◇ ステップ3｜3つの材料で、1行にする（7分）

この型に入れます。

```
御社の〔場所〕、〔どんな状態か〕のが、
少しもったいないと感じました。
```

書けたら、送る前に3つ確認します。

```
□ 場所が1つに絞られているか
□ 困っているのが「相手のお客さん」になっているか
□ 言い切らずに終わっているか
```

3つ目が抜けると、だいたい偉そうになります。

  ◇ 書けないときの、3つの分かれ道

① 困りごとが見つからない

その会社のことが好きすぎる可能性があります。自分がお客として迷った瞬間を思い出してください。「どこを押せばいいか一瞬迷った」で十分です。

② 指摘がきつくなる

「〜が足りていません」ではなく、「〜が伝わりきっていない」に変えてください。足りないのは相手の責任、伝わりきっていないのは状況の話です。

③ 結局、自分の説明を足したくなる

足さないでください。あの1行にも、できることは一言も書いていません。説明は「詳しく聞かせてください」と言われたあとで足ります。

  ▶ 今日は、1社ぶんの1行が書けたら終わりで大丈夫です。送らなくても構いません。

■ おわりに

120万円かけた作品集は、8年間、一度も開かれていません。

決め手になったのは、作品を1枚も添えずに送った1行でした。

もし今、「まだ作品が足りない」「もっと上手くなってから応募しよう」「ポートフォリオが完成していないから動けない」と思っているなら、一度だけ順番を疑ってみてください。

作品を増やす前に、相手を見る。

これが、120万円かけて122件落ちた私が、8年前にいちばん最初に知りたかったことです。
