タイトル：投稿の書き出しばかり直していました。485本を数えたら、差が出ていたのは最後の1文字でした
タグ：Threads / SNS発信 / フリーランス / 個人起業

==============================================


「どうしたら伸びますか」

いちばんよく聞かれる質問です。

少し前の私なら、書き出しの話をしていたと思います。実際、自分の投稿も1行目ばかり直していました。

```
「〇〇な人、いませんか？」で始めてみる
数字を頭に持ってくる
セリフから入る
```

どれも、よく言われていることです。やってみて、伸びる日もありました。でも、何が効いたのかは最後まで分かりませんでした。

プロフィールを直したあとに、今度は投稿そのものを数えてみました。

そうしたら、1行目ではないところで差が出ていました。

■ 自分の投稿を、485本ぶん書き出しました

スレッドの1投稿目だけを、全部書き出しました。485本です。

数えたのは、この3つだけです。

```
1｜文字数
2｜改行の数
3｜最後の1文字
```

内容の良し悪しは数えていません。自分では判断できないからです。形だけを数えました。

数える前は、文字数で差が出ると思っていました。短いほうが読まれるはずだ、と。

結果を見たら、文字数ではありませんでした。

［図1］数えたのは、この3つだけ

■ 差が出ていたのは、最後の1文字でした

いちばん読まれた15本を並べました。

15本とも、「。」で終わっていました。

次に、「、」で終わっている投稿を数えました。47本ありました。

この47本に、上位は1本もありませんでした。

  ◇ 私がやっていたのは、こういう形です

心当たりがありました。私はこう書いていたからです。

```
×  122件応募して、全部落ちました。理由が分からなくて、
   応募文を全部読み返したんですが、
```

続きを読ませようとして、途中で切っていました。「気になるでしょ？」という書き方です。

書いているときは、うまい切り方をしたつもりでした。「ここで止めたら気になるだろう」と思って、わざと途中で切っていたんです。

上位15本を見るまで、それが効いていないとは思っていませんでした。

  ◇ 理由は、断定できません

なぜ差が出たのか、正直はっきりとは分かりません。読まれ方は、テーマや時間帯にも左右されます。

ただ、485本を並べたときに、そこだけがきれいに分かれていたのは確かでした。

ひとつ思い当たるのは、読点で終わる文は書き手の都合だということです。自分はまだ書きたい。だから切る。読む側は、途中で止められているだけです。

句点で終わると、読む側に「で、どうなったの」が残ります。

  ▶ まずここだけ持ち帰ってください。直すのは書き出しではなく、終わり方かもしれません。

［図2］上位15本は、全部「。」で終わっていた

  ◇ 今日、無料でできること

直近の5投稿を開いて、最後の1文字だけを見てください。

```
。 が何本？
、 が何本？
```

それだけです。書き直さなくて大丈夫です。

「、」が多かったとしても、落ち込まなくていいです。私の485本も、そうでした。

ここまでが、最後の1文字の話です。

ただ、終わり方を直しても、読まれる前に閉じられている投稿がありました。数えたら、そこにもはっきり差が出ていました。

この先に書くのは、改行の数で何が変わったか、500字をどう使ったか、そして句点で終わる形への直し方です。

━━━━━━━━━━━━━━━━━━━━━━━━
★★★  ここから有料エリア（100円）  ★★★
   note編集画面で、この位置に有料ラインを引く
━━━━━━━━━━━━━━━━━━━━━━━━

■ 改行のない投稿は、半分しか読まれていませんでした

485本のうち、改行が1つも入っていない投稿が98本ありました。

その98本の、見られた回数の中央値です。

```
改行なし（98本）　　　1,278回
改行あり　　　　　　　2,000〜2,600回
```

中央値で、半分くらいでした。

  ◇ 文字数は同じでも、見え方が違います

Threadsは、1画面に入る文字数が多くありません。改行がないと、ひとかたまりの文字の壁になります。

読む人は、内容を読む前に長さだけを見て判断しています。私もそうです。

同じ246字でも、3つに割ってあれば読み始められます。

  ◇ どこで改行するか

迷ったら、この3か所です。

```
1｜最初の1文のあと（必ず切る）
2｜話が変わるところ
3｜いちばん言いたい1文の前
```

3つ目だけ、少し意識が要ります。言いたい文の前で1行あけると、そこだけ浮きます。

［図3］改行があるかないかで、中央値が倍近く違った

■ 500字を、全部使わない

Threadsの1投稿は、500字が上限です。私の485本のうち、ちょうど500字の投稿もありました。

一方、1投稿目の文字数の中央値は246字でした。だいたい半分です。

短いほど伸びたわけではありません。でも、長いほど伸びたわけでもありません。

  ◇ 1投稿目に入れるもの

入れているのは、この3つだけです。

```
1｜誰の話か（セリフ、または自分の失敗）
2｜何が起きたか（数字が1つあると強い）
3｜言い切り（句点で終わる1文）
```

  ◇ 1投稿目に入れないもの

逆に、1投稿目から外したものです。

```
・解決策
・自分の肩書きや実績の説明
・リンク
・「続きはリプ欄で」という案内
```

解決策を1投稿目に入れると、そこで終わります。肩書きは、気になった人がプロフィールを見ます。

■ 「、」で切っていた投稿を、直してみます

実際の直し方です。3つ並べます。

①途中で切っている

```
×  122件応募して、全部落ちました。理由が分からなくて、
   応募文を全部読み返したんですが、

○  122件応募して、122件落ちました。
   応募文を全部読み返して、理由が分かりました。
```

答えは言っていません。でも、文としては終わっています。

②説明が続いている

```
×  デザインの仕事を8年していて、その中で気づいたことがあって、

○  8年やってきて、いちばん驚いた一言があります。
```

③問いかけで逃げている

```
×  みなさんは、どうしていますか？

○  私は、2年間まちがえていました。
```

問いかけは答えやすい反面、書き手が何も差し出していません。自分の側から1つ出すほうが、続きが読まれました。

■ 実際にやってみる（15分）

［図4］直近5投稿の、最後の1文字

  ◇ ステップ1｜最後の1文字を書き出す（3分）

直近5投稿の、最後の1文字だけを書き出します。本文は読まなくて大丈夫です。

「、」が3つ以上あれば、そこが直す場所です。

  ◇ ステップ2｜1本だけ、句点で終わる形に直す（7分）

全部はやりません。1本だけです。

切っていた文を、最後まで書き切ってください。答えは書かずに、文だけ終わらせます。

  ◇ ステップ3｜改行を2か所入れる（5分）

直した1本に、改行を2つ入れます。最初の1文のあとと、いちばん言いたい文の前です。

  ◇ うまくいかないときの、3つの分かれ道

① 句点で終わらせると、続きを読んでもらえない気がする

いちばん多い不安だと思います。私もそうでした。実際には、終わっている文のほうが上位に多かったというだけの話です。1本だけ試して、自分の数字で確かめてください。

② 書き切ると、答えまで言ってしまう

「何が起きたか」で止めて、「なぜそうなったか」を書かなければ大丈夫です。上の①の例が、その形です。

③ 改行を入れると、間延びして見える

入れすぎています。2か所で十分です。1行ごとに改行すると、今度は内容が薄く見えました。

  ▶ 今日は、1本直せたら終わりで大丈夫です。過去の投稿は、そのままで構いません。

■ おわりに

485本を数えるまで、私は書き出しだけを直していました。

数えたあとで分かったのは、形のほうに差が出ていたということです。内容が同じでも、終わり方と改行で、読まれ方が変わっていました。

これは私の投稿を数えただけの話です。あなたの投稿では、別のところに差が出ているかもしれません。

ただ、自分の投稿を数えてみるところまでは、今日できます。 5本ぶん、最後の1文字を見るだけです。

伸びない理由は、たぶん、思っているより小さいところにあります。
