# ココナラ「愚痴聞き・ストレス解消相談」調査（2026-09-03）

対象サービス：**「もう全部めんどくさい」ママの愚痴聞きます — 家事、育児、夫、仕事、夕飯、全部OK**
目的：実績ゼロ・無資格でも「今すぐ相談したい！」層に見つけてもらい、依頼につなげる。

## 成果物

- `coconala_guchikiki_research.xlsx`
  - `01_検索ワード` … 優先度A/B/C付きの検索ワード 38語
  - `02_感情ワード` … 購入者の心の声＋そのまま使える言い回し 35語
  - `03_売れてる実例` … 実在の出品タイトル＋キャッチ 24件（URL付き）
  - `04_タイトル案` … 上記から組んだタイトル／キャッチ案 6案＋実績ゼロ期の打ち手
  - `05_順位記録` … 毎日の順位を記録するシート（黄色セルのみ入力、通算順位は自動計算）
  - `06_調べ方メモ` … シークレットタブでの順位確認手順

## 調査でわかったこと（要点）

1. カテゴリ規模は大きい（「話し相手・愚痴聞き」は出品 約6.8万件／実績31万件）。
   真正面の「愚痴聞きます」だけでは埋もれる。**複合ワードで小さな一位を取る**のが実績ゼロの定石。
2. 売れている出品のタイトルは**検索ワードの羅列型**が多い
   （例：「ワンオペ育児 ワーママ 愚痴 不満受け止めます」）。
3. キャッチは**購入者のセリフをそのまま書く**型が強い
   （例：「使えない旦那に腹立つー！イライラする！顔も見たくない！」）。
4. 効いている3系統のワード
   - 状況ワード：ワンオペ育児／ワーママ／主婦／産後／ママ友
   - 感情ワード：もう無理／しんどい／イライラ／モヤモヤ／ぶちまける／誰にも言えない
   - 安心ワード：秘密厳守／匿名／否定しない／全肯定／24時間／即レス
5. **「夕飯・献立がめんどくさい」は愚痴聞きカテゴリでほぼ使われていない**。
   あなたのコンセプトの中で最も差別化しやすい切り口。

## 注意

本セッションの実行環境はネットワークポリシーにより `coconala.com` への直接アクセスが
ブロックされている（`EGRESS_BLOCKED`）。そのため**実際の検索順位はこの環境からは取得できていない**。
順位は `06_調べ方メモ` の手順で手動計測し、`05_順位記録` に記録すること。
