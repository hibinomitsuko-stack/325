### 発信の全体構造（記事を書くときの土台）

大テーマ：**選ばれる人になる**

- STEP1：まず最初の1件を作る（ココナラ・電話相談・モニター・既存プラットフォームなど）
- STEP2：実績を言語化する
- STEP3：Threadsなどで発信する
- STEP4：自分の商品・サービスへつなげる

デザイナー向けには、案件獲得・ヒアリング・提案・見積もり・クライアント対応。
個人起業家向けには、Threadsでの発信設計、既存プラットフォームを使ったゼロイチの実績づくり、商品販売への導線設計。

どちらにも共通して伝えているのは、**「もっとスキルを増やす」「フォロワーを増やす」「安くする」だけが選ばれる方法ではない**ということ。
「自分に何ができるか」ではなく、**相手が何に困っていて、何を理由に自分を選ぶのか**を見る。これが軸。

## 3. 文章のトーン

| 項目 | 内容 |
|---|---|
| 一人称（自分の呼び方） | 私 |
| よく使う語尾 | ですます調。「〜なんです」「〜でした」を軸に、短い言い切りや体言止めを混ぜる。同じ語尾を続けない |
| 避けたい言い回し | 教科書的な書き出し（「近年〜」「〜について解説します」）／答えを冒頭で全部言ってしまう書き方／誇大な表現（絶対・必ず・誰でも・100%） |
| 敬語のレベル | ですます調。読者ひとりに向かって話しかける距離感 |

### 文章の型（サンプル文に共通する組み立て）

**第三者のセリフ → 常識を壊す → 自分の実体験 → 答えをすぐには言わない**

この型を、noteでもそのまま使う。

### あなたが書いた文章のサンプル

> 下ほど優先度が低い。書くときは上の2本のリズムを最優先で真似る。

**【優先1】ポートフォリオ？見てないですよ**

```
「ポートフォリオ？見てないですよ」

120万円かけて作ったポートフォリオを、一度も見せずに仕事が決まりました。納品直前、思い切って聞いてみたんです。「じゃあ、何を見て私に決めたんですか？」返ってきた答えは、作品の話ではありませんでした。
```

**【優先2】122件応募して122件落ちた**

```
122件応募して、122件落ちました。

毎日応募していました。ポートフォリオも直した。提案文も丁寧に書いた。募集文も最後まで読んだ。それでも仕事はゼロ。「まだ実力が足りないんだ」と思っていました。でも、あとから応募文を全部読み返して気づきました。私は122件、相手のことではなく、自分の自己紹介を送り続けていたんです。
```

**【優先3】ゼロイチを作った受講生の実例**

> ※これは仮の文章。実際の受講生の経緯・数字が分かったら、この枠を差し替える。

```
フォロワーを増やす前に、最初の1件を取りにいきました。

Threadsで発信を始めると、「まずフォロワーを増やさなきゃ」と思いがちです。でも、実績ゼロの受講生には、発信だけを続けてもらうのではなく、ココナラの電話相談など、すでにお客様がいる場所も使ってもらいます。最初に必要なのは、1,000フォロワーではなく、「お金を払ってでも相談したい」と言ってくれる1人を作ることだからです。
```

**【優先4】スクールに通ったのに仕事0件**

```
デザインスクールを卒業しました。1年後、仕事は0件でした。

スキルが足りないと思って、また勉強しました。Illustrator、Photoshop、LP、WordPress。できることは増えた。でも仕事は増えない。当時の私は「作れる人」にはなっていたけれど、「頼みたい人」にはなれていませんでした。この違いに気づくまで、かなり時間がかかりました。
```

**【優先5】返信遅いですよね。でもその方が助かってます**

```
「返信遅いですよね。でもその方が助かってます」

クライアントに言われて、意味がわかりませんでした。5年前、私は「返信が遅い」という理由で取引を切られています。なのに今度は、「遅い方が助かる」と言われた。理由を聞いたら、「一回で話が進むからです」と言われました。
```

## 9. 記事を書くときの約束

- **「ココナラ」「電話相談」を記事の上位テーマにしない。** タイトルや大見出しの主役にもしない。あくまで STEP1「最初の1件を作る」ための手段の一つとして、本文の中で扱う。ここが寄ると「ココナラ攻略の人」に見えてしまい、書けるネタが狭くなる
- 解決策として「もっとスキルを増やす」「フォロワーを増やす」「安くする」を推さない
- デザイナー向けの話と、Threads起業家向けの話を分断しない。どちらも「実績ゼロから、選ばれる状態を作る」という同じ世界観の中で書く
- 記事の主語は「自分に何ができるか」ではなく「相手が何に困っていて、何を理由に選ぶか」
- 数字や実績は盛らない。断定を避け、事実として確かめられることだけ書く

## 10. 有料記事の作り方（毎日1本・100円）

noteは**毎日1本、100円の有料記事として販売する**。Threadsの投稿が事前にあってもなくても、同じ形で出す。
目的は売上ではなく、**買ってくれた人を教育すること**。100円は、読む気のある人だけを通すための線。

### 記事の形（毎回この2層で書く）

**無料部分**（全体の 40〜50%／1,200〜1,500字）
- 読者の「あるある」か、第三者のセリフから入る
- 何が問題だったのかを言い切る（＝気づきは無料で渡す）
- 具体策の1つ目までは無料で渡してよい。出し惜しみしない
- 最後は句点で完結させ、答えは出さない

**有料部分**（全体の 50〜60%）
- 残りの具体策
- 判断の基準（なぜそうするのか）
- **実践セクションを必ず入れる**（所要時間つきの手順＋空欄を埋めるワーク＋図解）
- 「書けないときの分かれ道」など、つまずきへの分岐
- 最後にCTA（LINE登録）

### 有料ラインの引き方

- 無料部分の最後に、**橋渡しを3〜5行**置く。これから何が書いてあるかを示し、答えは言わない
  - 例：「ここまでが3つのうちの1つ目です。残りの2つと、実際に書くところまで書きます。」
- Threadsで先に出した内容は、**必ず無料側に置く**。既読の話に課金しない
- 答えが分かってしまう図解は、有料側に置く

### 守ること

- 無料部分だけでも、読んで何か持ち帰れる状態にする（ただの予告にしない）
- 100円であることを隠さない。Threadsからリンクするときは「途中まで無料で、続きは100円です」と書く
- 買った人に向けて、必ず**今日できること1つ**で終える
