タイトル：デザインが上手い人から、落ちていきました。122件落ちた私が、応募をやめて始めたこと
タグ：フリーランス / デザイナー / 案件獲得 / 営業 / 個人起業

==============================================


「スクールで一番上手かった人が、まだ1件も決まっていないらしいです」

そう聞いたとき、正直、驚きませんでした。

私も13ヶ月、同じ状態だったからです。

クラウドワークスに122件応募して、決まったのは0件でした。ポートフォリオも提案文も、毎回直していました。

当時送っていたのは、だいたいこういう文です。

```
デザイナーの日比野と申します。
LP・バナー制作が可能です。
ポートフォリオはこちらです。
よろしくお願いいたします。
```

返事は、ほとんど来ませんでした。

あるとき、送る文を変えました。自分の説明をやめて、相手のページで「もったいない」と思ったところを3つ書いて送ったんです。

そこから、送った42件のうち23件が決まりました。

デザインの腕は、1ミリも変わっていません。

■ 変えたのは、順番だけでした

やっていたことの違いは、これだけです。

```
これまで｜募集を待つ　→　自分を説明する　→　作品を見せる
変えた後｜相手を見る　→　問題を3つ書く　→　作品は送らない
```

応募は、相手が「困っている」と公開してくれるのを待つ形です。待っているあいだ、こちらにできることは自分を磨くことしかありません。

だから私は、ポートフォリオを直していました。順番として、そこしか触れなかったんです。

一方で、相手を先に見にいく形だと、募集が出ていなくても動けます。待つ時間が、そのまま作業時間になります。

［図1］応募と、見つけて送るの違い

■ 上手い人ほど、作品で伝えようとします

3年ほど、デザイナーの方の相談を受けてきました。100人以上は見ていると思います。

そのなかで感じているのは、決まっている順番が、腕の順番と一致していないということです。

上手い人ほど、作品で伝わるはずだと思っています。私もそうでした。実際、作品を見てもらえれば伝わると思います。

ただ、相手は作品を見る前に、別のことを確かめています。

「この人、うちのことを見てくれているのか」です。

  ◇ 「ポートフォリオを見せてください」とは言われません

122件のうち、「ポートフォリオを見せてください」と言われたことは一度もありませんでした。

見せて落ちたのではなく、見せる手前で終わっていたんです。

そこを直さずに作品だけ増やしても、同じところで止まります。私は13ヶ月、その場所で止まっていました。

今振り返ると、作品を増やすのはいちばん安全な作業でもありました。相手に見られないので、断られることもないからです。

  ▶ まずここだけ持ち帰ってください。落ちている場所は、作品より手前かもしれません。

  ◇ 今日、無料でできること

楽天でも、Amazonでも、Instagramでも構いません。

「もったいない」と思うお店を、1つだけ見つけてください。

探すコツは3つです。

```
・商品は良さそうなのに、ページが見づらい
・レビューは良いのに、写真が暗い
・投稿の内容は良いのに、何の人か分からない
```

5分から10分で見つかります。まだ何も送らなくて大丈夫です。

ひとつだけ。「自分ならもっと上手く作れる」と思った店は、いったん外してください。それは自分の話に戻っています。

探すのは、客として引っかかった店です。買おうとして、どこかで手が止まった。その感覚が、そのまま3つになります。

［図2］「もったいない」お店の見つけ方

ここまでが、順番の話です。

ただ、見つけたあとが難しいと思います。何をどう書けば、ダメ出しにならずに届くのか。

この先に書くのは、実際に送って決まった文の作り方を3ステップに分けたものと、そのままの営業メール、そして15分の手順です。

━━━━━━━━━━━━━━━━━━━━━━━━
★★★  ここから有料エリア（100円）  ★★★
   note編集画面で、この位置に有料ラインを引く
━━━━━━━━━━━━━━━━━━━━━━━━

■ ステップ1｜ダメなところを、3つ見つける

専門知識はいりません。自分に3つ聞くだけです。

```
1｜自分がお客さんだったら、買いたくなるか
2｜友達にすすめたいと思うか
3｜スマホで見たとき、分かりやすいか
```

実際にあった例です。手作り石鹸を探していて、商品は良さそうなのにページが残念なお店を見つけました。

```
1｜商品画像が暗くて、質感が分からない
2｜説明文が長すぎて、途中で読むのをやめた
3｜他の石鹸との違いが書かれていない
```

メモしたのは、これだけです。分析もリサーチもしていません。

  ◇ 3つ、というのが大事です

1つだと、たまたまに見えます。5つ以上だと、ダメ出しの一覧になります。

3つは、見た人が「ちゃんと見てくれたんだな」と感じる最小の数でした。

［図3］もったいないを3つ見つける

■ ステップ2｜なぜそう思ったかを、一言で言う

見つけても、伝え方で結果が変わります。

よくない書き方が2つあります。

```
×  デザインがイマイチですね
   → 何を直せばいいのか分からない

×  もっとプロっぽくしたほうがいいです
   → 上から目線に聞こえる
```

直すと、こうなります。

```
○  商品画像が暗いので、お客様が質感を想像しにくいかもしれません

○  説明文が長いので、スマホだと途中で離れてしまう方がいそうです
```

違いは2つです。具体的であることと、困るのが相手ではなく「相手のお客さん」であること。

「あなたのページが悪い」ではなく、「あなたのお客さんが困りそう」にすると、同じ指摘でもダメ出しになりません。

  ◇ 数字は、約束しないでください

ここだけ、強く書きます。

「この3点を直せば、売上が2倍になります」と書きたくなります。実際、そう書いてあるテンプレートも見かけます。

書かないでください。

まだ何も調べていない相手の売上を予測することはできません。そして、約束した数字に届かなかったときに残るのは、仕事ではなく不信です。

書くなら、こうです。

```
この3点を直すと、商品の良さが今より伝わりやすくなると思います。
```

言い切らないほうが、むしろ返事が来ました。

■ ステップ3｜どう直すかを、ざっくり伝える

ここで多くの人がやってしまうのが、完璧な改善案を作り込むことです。

私もやりました。返事が来る前に、修正版のデザインまで作って送っていました。

時間がかかるうえに、方向が外れていたら全部無駄になります。そして受け取った側は、「ここまで作られたら断りにくい」と感じます。

伝えるのは、方向だけで足ります。

```
1｜商品画像を明るく撮り直す（白背景で、質感が分かるように）
2｜説明文を3つのポイントに絞る
3｜「他との違い」を1行足す
```

  ◇ 実際に送った文

そのまま載せます。

```
突然のご連絡失礼いたします。
デザイナーの◯◯と申します。

楽天で石鹸を探していて、御社の商品を見つけました。

商品ページを拝見して、もったいないと感じた点が3つあります。

1. 商品画像が暗く、質感が伝わりにくい
2. 説明文が長く、スマホでは途中で離れてしまいそう
3. 他の石鹸との違いが分かりにくい

この3点を直すと、商品の良さが今より伝わりやすくなると思います。

もしご興味があれば、簡単な改善案をお送りします。
まずは画像だけでも構いません。
```

専門用語は1つも使っていません。ポートフォリオも添付していません。

最後の「まずは画像だけでも」が効きます。全部やりましょうと言われると、相手は金額も時間も読めずに止まります。

■ 実際にやってみる（15分）

［図4］1通ぶんの、もったいないシート

  ◇ ステップ1｜お店を1つ見つける（5分）

自分が買ったことのあるお店にしてください。客として見たときの記憶が残っているほうが、具体的に書けます。

  ◇ ステップ2｜もったいないを3つメモする（5分）

上の3つの問いを使います。専門的に書かなくて大丈夫です。「ここ、見づらいな」で十分です。

  ◇ ステップ3｜1通だけ書く（5分）

上の型に入れて、1通書きます。送らなくて構いません。

書けるかどうかを確かめるのが今日の目的です。送るのは、書けると分かってからで足ります。

  ◇ うまくいかないときの、3つの分かれ道

① もったいないところが見つからない

そのお店が自分の好みに近すぎます。まったく興味のない業種を見てください。思い入れがないほうが、客として見られます。

② 書くと、きつくなる

主語を確認してください。「御社のページは」で始まっていたら、「御社のお客様は」に変えます。それだけで角が取れます。

③ 書いたけれど、送るのが怖い

私も最初はそうでした。送らなくていいです。ただ、書いた3つを、自分の作品の説明に使ってみてください。 同じ形で書けるようになります。

  ▶ 今日は、1通ぶん書けたら終わりで大丈夫です。

■ おわりに

13ヶ月、案件はゼロでした。122件応募して、決まったのも0件でした。

そのあいだ私がやっていたのは、作品を増やすことと、提案文を丁寧にすることです。どちらも、自分の側の話でした。

変えたのは、先に相手を見るということだけです。

デザインの腕は、そのとき何も変わっていません。評価だけが変わりました。

もし今、「上手くならないと営業できない」と思っているなら、順番が逆かもしれません。

見つけることは、今日からできます。
