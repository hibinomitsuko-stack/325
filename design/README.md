# 図解のデザイン（ネオン版 v2）

noteに差し込む図解は、**すべてこのデザインで作る**。毎回ゼロから考えない。

## 使い方

1. `base.css` を記事フォルダの `figs-source/` にコピーする
2. 図解のHTMLの先頭で `@import url("base.css");` と書く
3. `node scripts/render-figure.mjs figs-source/figN.html images/figN.png 1600 <高さ>` で書き出す

高さは図ごとに決める（目安 760〜900px）。幅は必ず1600px、2倍解像度で書き出す。

## 決まっていること（触らない）

| | |
|---|---|
| 背景 | 濃紺→紫のグラデーション。左上に斜めストライプ、右上にネオンの斜め線、左上と右下にドット |
| 見出し | 白の極太。**いちばん強調したい語だけ** 蛍光イエロー＋下線（`<span class="o ul">`） |
| 本文 | 白。補足は薄い青（`--ink2`） |
| カード | 角丸22px、グラデーションの枠（シアン→紫→マゼンタ）、外側に発光 |
| 下の帯 | 紫→マゼンタのグラデ。黒丸＋蛍光イエローのチェック。強調語は `<span class="hl">` |

## 使えるクラス

- `.head` + `h1` … 上の見出し。強調語は `<span class="o ul">語</span>`
- `.neon` … 標準のカード（シアン寄りの枠）
- `.neon.m` … マゼンタ寄りの枠。**言いたいほう・正解のほう**に使う
- `.neon.dim` … 弱い枠。**比較の「よくないほう」**に使う
- `.foot` … 下のまとめ帯。中は `<span class="ck">…</span><span>文…<span class="hl">強調</span></span>`

## 色を変えたいとき

`base.css` の `:root` だけ書き換える。個別の図解では色を直接書かない。

```css
--neon:#d9ff3d;  /* 蛍光イエロー：いちばん強調したい語 */
--mag:#f026c8;   /* マゼンタ */
--cyan:#23c9ff;  /* シアン */
--vio:#8b3cf7;   /* 紫 */
```

## 書き出したら必ず見る

- 文字が帯に隠れていないか（隠れていたら**高さを増やす**。文字は小さくしない）
- 縦書き（`writing-mode`）は使わない。日本語が重なって崩れる
- 1枚に入れる要素は**3〜4個まで**
