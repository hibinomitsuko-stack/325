```
①コメントを増やしたい →「同じ人いますか？」と問いかける

③フォローされたい →「このアカウントでは◯◯を出していきます」と次を約束する
```

```
今日の投稿の最後の1行を、この3つのどれか1つに書き換えてください。1分でできます。
「参考になれば嬉しいです」で締めて、また反応ゼロを待つのか。最後の1行で、読んだ人の次の行動を決めるのか。
締めのない投稿は、読み終わった人を置き去りにしています。
```

## 11/24（火）20:07｜夜｜体験・過去の自分への毒

**【1スレッド目】**
```
「来月から、来なくていいから」
18ヶ月働いた会社を、その一言でクビになりました。
```
**【2スレッド目】**
```
理由は、はっきり3つでした。
「センスがない。遅い。向いてない」
反論しませんでした。全部その通りだと思ったので。
帰り道、うつむいてトボトボ歩きながら、恥ずかしくて、悔しくて、家に帰りたくなかった。
あんなに帰り道が長いと感じたことは、後にも先にもありません。
```
**【3スレッド目】**
```
そのあと1年半、仕事がありませんでした。
でもその時間で、あの3つの言葉を1つずつ分けて考えることができたんです。
「センスがない」は、感覚で選んでいて、理由を言えなかったから。
「遅い」は、決められなかったから。
「向いてない」だけは、今も違うと思っています。
3つのうち2つは、直せることでした。
```
**【4スレッド目】**
```
発信を続ければ、否定的なコメントは必ず来ます。
そのときは、言葉を1つずつ分けてみてください。
まとめて受け取ると、全部が自分の否定になる。
分けると、明日やることが1つ見つかります。
私はそれに気づくのに、1年半かかりました。
```
