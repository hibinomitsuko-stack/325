```
つまり、投稿を読んだ人が最初に目にする「看板」なんです。
私の場合、名前欄を「みつこ｜陰キャのスレッズ集客法」にしています。
名前だけのときと比べて、「何の人か」が一目で伝わるようになりました。
名前欄の作り方は、この形だけです👇
```
**【3スレッド目】**
```
「名前｜誰の、どんな悩みを解決する人か」
例：
❌「みつこ」
⭕「みつこ｜陰キャのスレッズ集客法」
❌「ゆか」
⭕「ゆか｜40代からの子育てママ起業」
ポイントは、職業名ではなく、読む人の悩みや目指す姿を入れることです。
```
