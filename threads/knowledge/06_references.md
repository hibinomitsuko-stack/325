# 06 参考投稿（伸びた投稿の見本帳）

構造の見本として使う。文章の丸写しは禁止。新アカウントは「Threads集客」がテーマなので、
デザイナー時代の話は「体験 → 気づき → 集客・発信にも同じことが言える」と橋渡しして使う（見本8の最後の1本がお手本）。

## 伸びる型の共通点（10本の比較から）
1. 1行目は他人のセリフ（「」）か、数字の落差。ノウハウから入った投稿は伸びが1桁小さい
2. 1本目は答えを出さずに切る。続きを読ませてから気づきとステップを出す
3. 失敗の具体的な数字（122件、時給300円、修正9回、4週間、深夜2時）が必ず入っている
4. 夫・上司・クライアントなど「登場人物」がいる
5. コメント欄は読者が自分の体験を語る長文コメントで埋まる＝共感型。保存より会話を生む

## 参考：2025年の「はっきり言うけど」型（2〜12万閲覧）
