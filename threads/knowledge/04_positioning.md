# 04 ポジショニング（似た発信者との違い）

## よくある発信者
- 顔出し・キラキラ・「毎日10投稿しよう」系の根性論
- 陽キャ前提の集客（DM営業、ライブ配信、交流会、コメント周り）
- 「AIで投稿を量産」系（誰が書いても同じ文章になる）

## みつこだけが言えること
- 陰キャ・ビビリの当事者として、怖さをごまかさずに語れる
- 顔出しなし・文字だけで仕事が来ることを、自分で実証している（39日で1,745人、前アカウント最高945,219閲覧）
- 性格を直すのではなく「性格に合う発信方法」を設計できる
- 元デザイナーとして「誰に何を伝えるか」「本人も気づいていない魅力を引き出す」ことが本業だった
- AIに仕事を奪われかけた側から、AIを時短に使いつつ代替されない発信の軸を教えられる

## 自分だけのエピソード（投稿の核として繰り返し使う）

### エピソード1：AIに、3年間の取引先を失いかけた日
3年間仕事をくれていたクライアントから、ある日突然「AIで何でも作れるので、もう依頼しません」と言われた。
反論できなかった。実際、デザイナーの作業の7割程度はAIで作れるようになっていたから。
ところが1週間後、「やっぱり、なんか違うのでお願いしたいです」と連絡が来た。
AIにできないのは「作ること」ではなく、次の4つだと気づいた。
- 誰に何を伝えるのかを決める
- 本人も気づいていない魅力を引き出す
- 何を作るべきかを判断する
- 違和感の原因を言語化する
それ以降、AIに丸投げせず、その人の経験や専門性を引き出したうえでAIを時短に使うようになった。
→ 伝わる強み：AIの使い方だけでなく「AIに代替されない発信の軸」まで設計できる。AI×Threadsを教える原体験。

### エピソード2：顔出しも営業も苦手だった私に、Threadsから仕事が来た
会社をクビになったあと自信を失い、営業を避けて2年間勉強に逃げた。新しい講座・ツール・技術を学び続けても仕事にはつながらなかった。
Instagramも始めたが、画像づくりが大変、リールが苦痛、顔を出したくない、人と話すのが苦手で続かなかった。
Threadsで自分の失敗や経験を文章で書くようになると、開始39日でフォロワー1,745人、投稿を見た人から仕事が来るようになった。
キラキラした成功者に見せるのではなく、クビになったこと・案件が取れなかったこと・時給300円で働いたこと・営業が怖かったことを隠さず書いたことが、相談や仕事につながった。
→ 伝わる強み：顔出しや動画が苦手でも、経験を言葉に変えれば仕事になることを本人が実証している。

### エピソード3：陰キャだから、普通の営業方法が全部つらかった
営業が怖くて2年間勉強に逃げた。クラウドワークスでは122件応募して全部不採用。異業種交流会や名刺交換も消耗するばかり。
「明るく社交的に振る舞わなければ」と思い、合わない営業方法を続けていた。
変えたのは性格ではなく方法。提案文の最初の1行を「自分のアピール」から「相手の問題を見る文章」に変えたら、翌月19件受注できた。
顔出しをしない別アカウントでは「海外移住って『行動力あるね』と言われるけど、実際は『国境をまたいだ引きこもり』です。」と、陰キャな部分をユーモアに変えて発信した。
陰キャを直すのではなく、次のやり方に変えた。
- 顔出しをしない
- 文章で伝える
- 失敗を自虐ではなくユーモアに変える
- 大勢に会わず、必要な人に届く導線を作る
- 相手を観察する力、一人で深く考えられる力を生かす
→ 伝わる強み：「SNSに向いていない性格」を矯正せず、その人に合う発信方法を設計できる。顔出し・リール・毎日の交流に疲れた40〜50代の先生、コーチ、ひとり起業家に特に刺さる。

### その他、使える実話（過去投稿より）
- 「もう二度と、依頼しません」：4週間かけ修正ゼロで納品したLPなのに、3日後に届いた一言（945,219閲覧）
- 「ねぇ、デザイナーなんて、もうやめたら？」：1年案件ゼロ、コンサルに10万円払ったのが夫にバレた夜
- 「来月から、来なくていいから」：18ヶ月でクビ。言われた3つのうち2つは直せることだった
- 「1万円だと、何を削りましょうか？」：値下げされなくなった質問
- 「そのクライアント、悪くないよ。きみの効率が悪いだけ」：夫の一言で修正9回→2回
- 「AIで作ったんですが、ここだけ直してもらえますか？」：AIのデザインには直す手がかりがない
- 7年で秘書が14人変わった社長の15人目の秘書になり、ニコニコで出てきた（基準値がバグっていた）
- 海外移住して意識低い系になったら体調が上がった（陰キャの隠居生活）
