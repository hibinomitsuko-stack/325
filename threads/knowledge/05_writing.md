# 05 文体ルール

## みつこの文体ルール10項目（2026-11-09 本人指定。1〜2は強豪と自分のバズ投稿、3〜10は本人の投稿3本から抽出。以降の原稿はこれを最優先する）
1. **1行目は、伸びた投稿（強豪＋自分）の型から毎回選ぶ**。「はっきり言うけど」「正直、」などの前置きは選択肢の1つにすぎない。同じ型を2投稿続けない

   |---|---|---|
   | 言われた一言 | 「（誰かに言われたセリフ）」 | みつこ（94.5万） |

   | NG断言 | 「絶対に手を出してはいけない◯◯」 | @gakikun_claudecode（28.4万） |

   | 許可×実績×まとめ | 「丸パクリOKです！ ◯ヶ月で◯◯まで伸びた◯◯まとめました」 | @shoko_hikaru_kotoba（3.14万） |

   | 共感あるある情景 | 「（読者の痛い場面）。◯◯は0。」 | @to.am_marke |
   | 断言＋不足 | 「断言します。◯◯できてない人。ここが足りてません。」 | @yuratea |
   | 共通点N個 | 「◯◯ばかりの人に絶対当てはまる共通点が5つあります。」 | @yuuyuuland |
   | ❌損してます | 「❌◯◯で、これやってる人損してます」 | @kudooo_ai |
   - 1行目を強くする部品（@shoko_hikaru_kotoba の5要素）：つぶやき枕詞（あのー。ねえ、正直…）／指示代名詞（これ、それ）／悩みの代弁（〜してるのに伸びない人）／ギャップ（実は逆です、9割が勘違い）／強い断定（結論から言います、断言します）。1行目に2つ以上入れる
2. **1行目の直後に、自分の数字か失敗を置く**：型が何であれ、2〜3文目で「私の場合〜」と確定した数字・失敗談を出して本当の話にする
   - 強豪の1本目は短い改行（1文1行、3〜5行）で切ることが多い。物語型は長い一文、ノウハウ型は短い改行と使い分ける
3. **語尾は「です・ます」が土台、要所で「〜んです」「〜なんです」**：説明の締めは「〜なんです。」「〜で決まるんです。」。言い切りの強調に使う
4. **ところどころ話し言葉を混ぜる**：「めっちゃ」「マジで」「死ぬほど重要なのは」「〜が命！」「〜しまくって」。1投稿に1〜2回まで
5. **一文の長さにメリハリ**：冒頭とストーリー部分は読点でつなぐ40〜80字の長い一文、ノウハウ部分は「・」の短い箇条書き（5〜15字）
6. **漢字は多め、ビジネス語とカタカナ語を自然に使う**：「導線」「信頼」「認識違い」「議事録」「ベネフィット」など。ただし専門用語には必ず具体例を添える（「例：」「例えば」）
7. **接続語で論理を見せる**：「実は」「つまり、」「なぜなら」「だから」「逆に」「私の場合」を多用。「〜と勘違いしている」「本当は〜」で常識をひっくり返す
8. **構造は「3つ」で見せる**：「①②③」「1) 2) 3)」「・」「→」「【】」「＜＞」で見出しと手順を作る。「以下順番に説明していきます👇」で本編へ入る
9. **締めは「今日からの3つ」＋仲間への呼びかけ**：最後に3つを短く再掲し、「〜してみてくださいね！」「一緒に積み上げていきましょう🔥」「一緒に頑張っていきましょう」で終える
10. **絵文字は締めと案内にだけ少し**：👇（本編へ）😊✨🔥（締め）。本文の途中には入れない。案内は最後に「P.S. でも自分の場合は〜という方は、プロフィールから〜」の形で1つだけ

### このルールを使うときの注意（運用ルールとの整合）
- 数字は 01_profile.md・10_students.md の確定値だけ。昔の投稿にある「80%減」「2.3倍」のような裏付けのない%は書かない
- 「バカでも」「人生終わります」など読者を下げる言葉は使わない（07_ng-rules.md）
- 構成（1行目の型、答えの手前で切る、CTAは1つ）は 06・09 のバズ構造に従い、言葉づかいだけをこのルールにする

## 以前の抽出（物語型の投稿から）

2026年の物語型の投稿（10万〜94万閲覧）と、2025年の「はっきり言うけど」型の投稿（2〜12万閲覧）では、
物語型の方が桁違いに伸びている。今後は物語型の文体を基本にする。

## 一人称・口調
- 一人称は「私」
- 本文は「〜でした／〜です」と「〜た。」の言い切りを混ぜる。感情が動く場面は短い「た。」で畳みかける
  - 例：「全部落ちた。心が折れた。」「何も言い返せなかった。」
- 説明やノウハウの部分は「〜です／〜ます」でやわらかく
- 自分を下げるときは自虐ではなくユーモアに（「国境をまたいだ引きこもり」「基準値がバグっていた」）
- 上から教えない。「私もそうだった」「〜年前の私だった」と同じ側に立つ

## 1行目（最重要）
- 誰かに言われた**キツい一言を「」で置く**のが最強の型
  - 「もう二度と、依頼しません」／「ねぇ、デザイナーなんて、もうやめたら？」／「来月から、来なくていいから」
- または、具体的な数字＋落差
  - 「2年間、時給300円で働いてた。」「2週間かけたデザインが、2時間で作ったデザインに負けた。」

## 本文の流れ（1本目＝500文字以内）
1. 1行目：言われた一言 or 数字の落差
2. 状況を具体的に：期間・回数・金額・時刻（「4週間」「深夜2時」「122件」「10万円」）
3. 体の反応・感情：「スマホを持つ手が震えました」「悔し涙が出た」「帰り道が長かった」
4. 意外な一言 or 結果だけ先に見せる：「でも提案文を変えたら翌月19件受注できた」
5. 最後は答えを言わずに切る：「その質問は」「後で知ったのは」「なぜなら、」「変えたのは、最初の1行だけだった。」

## 続き（コメント欄・2本目以降）の流れ
- 2本目：あの時の詳細と、当時の自分の勘違い
- 3本目以降：気づき → 具体的な3ステップ（変える前 → 変えた後、所要時間つき）
- Before/After を数字で並べる（「修正平均9回 → 2回」「返信率5% → 65%」）
- 最後：今夜からできること3つ（「合計10分です」など小ささを強調）＋「固定投稿から相談に来てください」程度の控えめな誘導
- 1本は500文字以内。分けるときは「---」で区切る

## 改行・記号
- 1本目は改行少なめで、ひと続きの文章として読ませる（物語型）。会話の「」で区切りを作る
- ステップ説明は ①②③ や STEP1 を使う。【】で見出しを作る
- 変える前／変えた後は「×」「○」または「→」で対比
- 絵文字は本文ではほぼ使わない。使うのは引用したセリフの中だけ（例：「完璧です！ありがとうございます✨」）
- コメント返信では 😊🙏 を1つ程度使ってよい

## コメントへの返信のしかた
- 相手の言葉を拾って、自分の体験を1つ足して返す。最後に「ありがとうございます」
- 反論・指摘にも感謝から入り、事実を補足する（例：ドイツの話だったので法律が違う、と丁寧に）
