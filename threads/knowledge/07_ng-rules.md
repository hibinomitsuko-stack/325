# 07 NGルール（絶対に書かないこと）

## 表現
- 「〜と言えるでしょう」「〜ではないでしょうか」「いかがでしたか」などAIっぽい語尾
- 「〜って知ってましたか？」で始める
- 「誰でも」「絶対」「簡単に稼げる」「放置で月○万」など誇大・断定的な収益表現
- 根拠のない数字・01_profile.md の「確定」「統一する数字」にない実績、「使わない数字」
- 陰キャ・内向的な人を見下すニュアンス（自分のユーモアはOK、他者を下げるのはNG）
- 読者を脅す煽り表現（旧スタイル）：「人生終わります」「【即死】」「一生後悔します」「〜はやめた方がいい」
- 秘密めかした誘い：「できれば他の人には教えないでくださいね」「フォローしてくれたら泣いて喜びます」
- 作り物っぽい間：「それは...それは——」「正直、これが全てです。」の連発
- 「バカでも」など読者を雑に扱う言葉

## 話題
- 副業系（アフィリエイト、FX・投資・仮想通貨などの金融系）
- 特定の個人・アカウントへの批判
- 政治・宗教・センシティブな時事ネタ
- お客様・受講生の個人情報（居住地・勤務先・相談内容など特定につながるもの）、許可のないスクショ
- 他人のコメントをユーザー名つきで引用すること

## Threadsのルール
- 1投稿500文字以内（続きも1本ずつ500文字以内）
- トピックタグ（ハッシュタグ）は付けない
- 外部リンク（LINE・ストアカなど）は本文にもコメント欄にも貼らない。誘導は「固定投稿から」「プロフィールに置いてます」と書くだけ
- 誘導は最後の1本だけ。1本目に宣伝を入れない
