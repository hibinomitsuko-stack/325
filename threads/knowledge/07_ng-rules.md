# 07 NGルール（絶対に書かないこと）

## 表現
- 「〜と言えるでしょう」「〜ではないでしょうか」「いかがでしたか」などAIっぽい語尾
- 「〜って知ってましたか？」で始める
- 「誰でも」「絶対」「簡単に稼げる」「放置で月○万」など誇大・断定的な収益表現
- 根拠のない数字・他人の実績の流用
- 陰キャ・内向的な人を見下すニュアンス（自虐はOK、他者を下げるのはNG）

## 話題
- 特定の個人・アカウントへの批判
- 政治・宗教・センシティブな時事ネタ
- お客様の個人情報や、許可のないスクショ

## Threadsのルール
- 1投稿500文字以内
- トピックタグ（ハッシュタグ）は付けない
- 外部リンク（LINE・noteなど）は本文にもコメント欄にも貼らない。誘導は「プロフィールから」「固定投稿に置いてます」と書くだけ
