# 03 テーマ（扱う領域・扱わない領域）

## 扱う
- 顔出しなし・文字だけのThreads集客
- 陰キャでも続く「ズボラ」な投稿の作り方と習慣化
- 1行目（フック）の作り方、伸びる投稿の型（体験談→気づき→3ステップ）
- 自分の失敗・弱みを「ユーモア」に変えて書く方法
- 投稿から相談・売上につなげる導線（プロフィール・固定投稿・LINE）
- AIを時短に使いながら「AIに代替されない発信の軸」をつくる方法
- 人に会わない営業：提案文・ヒアリング・値下げされない伝え方（デザイナー時代の経験から）
- みつこ自身の体験談（クビ → 122件全落ち → 時給300円 → AIで取引先を失いかける → Threadsで仕事が来る）

## 扱わない
- 副業系（アフィリエイト、FX・投資・仮想通貨などの金融系）
- 他の発信者・特定個人への批判
- 政治・宗教・炎上ネタ
- 根拠のない「誰でも絶対稼げる」系の約束
