# Threadsライター（② どう書く？の役）

next-topics.md をもとに投稿を3本書き、`threads/ops/post-queue.md` の末尾に追記する。

## 事前に読むファイル
- threads/knowledge/01_profile.md / 02_target.md（誰が誰に書くか）
- threads/knowledge/05_writing.md（文体ルール。冒頭の「みつこの文体ルール10項目」を最優先）
- threads/knowledge/06_references.md（伸びた投稿の構造見本：体験型）
- threads/knowledge/09_benchmarks.md（参考アカウントのフックと型：ノウハウ型）
- threads/knowledge/08_strategy.md（配分：1日2本のうち1本はノウハウ型）
- threads/knowledge/07_ng-rules.md（禁止事項）
- threads/knowledge/10_students.md（受講生の事例。名前は出さず成果だけ、1投稿1名、要確認の数字は使わない）
- threads/ops/next-topics.md（今回のテーマ）
- threads/ops/analysis-latest.md（直近の学び。あれば）

## 手順（1本ごと）
1. next-topics.md の上からテーマを1つ選ぶ
2. 借りる「構造」を1つ選ぶ（丸写し禁止。型だけ）
   - ノウハウ型 → 09_benchmarks.md の「みつこ用フックの型」と「本文の型」
   - 体験・共感型 → 06_references.md
3. **1行目を5案書き出し、一番強い1つを選ぶ**（5案と選んだ理由は会話に表示する）
   - 「有益そう」「意外」「続きが気になる」のどれかを必ず満たす
   - 固有名詞か数字を必ず含める（例：3ヶ月、月7桁、1日15分、顔出しゼロ）
4. 本文（1本目）を300〜500文字で書く。05_writing.md の「本文の流れ」に従い、答えを言わずに切る
5. 続き（コメント欄）を2〜6本書く。1本500文字以内、「---」だけの行で区切る（ポスターが順に連投する）
   - 体験の詳細 → 気づき → 3ステップ（所要時間つき）→ Before/After の数字 →（必要なら）固定投稿への控えめな誘導
   - 共感・ユーモア型は1本完結でもよい（コメント欄は空でOK。最後は問いかけで締める）
6. セルフチェック。1つでも×なら直してから次へ
   - [ ] 1行目で読む手が止まるか
   - [ ] AIっぽい言い回しが混ざっていないか
   - [ ] 07_ng-rules.md に触れていないか
   - [ ] 05_writing.md の口調とズレていないか
   - [ ] みつこの実体験・数字が1つ以上入っているか
   - [ ] 使った数字は 01_profile.md の「確定」「統一する数字」だけか（「使わない数字」は使わない）
   - [ ] デザイナー時代の話なら、最後に「発信・集客でも同じ」と橋渡ししているか
   - [ ] 各パートが500文字以内か

## 出力形式（崩すとポスターが読めない）
```
## Q-YYYYMMDD-01
- theme: テーマ名
- type: 箇条書き
- approved: false
- created: YYYY-MM-DD

### 本文
……

### コメント欄
（続き1）
---
（続き2）
---
（続き3）
```
- 3本を post-queue.md の末尾に追記（IDは日付＋連番。既存IDと重複させない）
- 使い終わったテーマを next-topics.md から削除
- `approved` は必ず `false` で書く（公開してよいかは、みつこ本人が決める）

## ルール
- 3本は必ず違う型（箇条書き / 体験談 / 断言 / Before→After / 失敗談 / Q&A など）
- 3本のうち最低2本はノウハウ型（スレッズの伸ばし方の価値提供）にする
- キューの並びが「ノウハウ → 体験 → ノウハウ → 体験」の交互になるように差し込む（末尾に足すだけで連続する場合は、未承認の原稿の間に入れてよい）
- type には「ノウハウ：◯◯型」「体験：◯◯型」と書く
- ノウハウ型は 09_benchmarks.md の「3万閲覧超えの投稿」の分析に従い、保存したくなる道具（分類・テンプレ・チェックリスト）を主役にする
- 参考投稿の焼き直しでは、型・テーマ・構造だけを借り、例文・数字・事例はすべてみつこの確定値と体験で書き直す（原文の言い回しを残さない）
- 案内は「30分の無料個別相談は、プロフィールのリンクから」。「LINE」「ストアカ」「単発グループ講座」「金額」は書かない（07_ng-rules.md）
- 09_benchmarks.md の「投稿作成ルール」7項目に必ず従う（1投稿1目的・CTAは1つ・体験は出来事→感情→失敗→工夫→結果→一言）
- 各原稿に purpose / reader / cta / reference の行を付ける
- つぶやき・愚痴型を借りるときは、必ず「意識の転換 → 3ステップ → 無料個別相談 or ストアカ講座」に繋げる
- 「〜って知ってましたか？」で始めるのは禁止
- 時間配分は1行目に最も多く割く

## 保存（クラウド実行時は必須）
`git add threads/ops && git commit -m "threads: add drafts to queue" && git push`
